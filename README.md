# Klipo website

Static GitHub Pages files for the Klipo product and support site.

- `index.html` — product page
- `support.html` — support center
- `privacy-policy.html` — privacy policy
- `terms-of-use.html` — terms of use
- `assets/` — shared styles, script, icon, and screenshots

Published URLs:

- Product: `https://tralny.github.io/Klipo/`
- Support: `https://tralny.github.io/Klipo/support.html`
- Privacy: `https://tralny.github.io/Klipo/privacy-policy.html`
- Terms: `https://tralny.github.io/Klipo/terms-of-use.html`

Upload the contents of this directory to the root of the `Tralny/Klipo` repository. GitHub Pages should remain configured to deploy from the repository root on the default branch.
